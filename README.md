# Словарные карточки

Одностраничный интерфейс конструктора обучающих карточек для начальной школы.

## Запуск

Требуется Node.js 22 LTS или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

Сейчас это frontend-прототип: кнопка генерации показывает результат-заглушку. На следующем этапе подключается API генерации изображения и API для заданий.

## Важно

Не размещайте реальные API-ключи в `page.tsx`, клиентском коде или GitHub. Ключи должны храниться в `.env.local` и использоваться только на серверной стороне.
